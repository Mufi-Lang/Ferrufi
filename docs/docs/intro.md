# About Ferrufi

Ferrufi is a next-generation, native macOS IDE specifically tailored for the **Mufi** programming language. It serves as both a high-performance development environment and a laboratory for cutting-edge editor technologies.

## Core Pillars

- **Mufi First:** Provides a first-class IDE experience for the Mufi language, including syntax highlighting, REPL integration, and integrated LSP support (diagnostics, hover, navigation).
- **Extreme Performance:** Uses Metal to offload text rendering and UI components to the GPU, ensuring 60+ FPS interactions even under heavy workloads.
- **Modern Architecture:** Employs modern techniques such as security-scoped resource management, advanced search indexing, and unified storage.
- **Native Experience:** Adheres strictly to macOS design patterns and system integrations.

## Target Audience

- **Mufi Developers:** Programmers who need a robust toolchain for writing and running Mufi.
- **Graphics Enthusiasts:** Developers interested in GPU-accelerated productivity software.
- **macOS Power Users:** Users who value lightweight, native, and fast software over cross-platform Electron alternatives.
