# if

Conditional branching.

## Syntax
```mufi
if (condition) {
    // code
} else if (condition) {
    // code
} else {
    // code
}
```

## Description
Executes a block of code if the specified condition is true.

## Examples
```mufi
if (x > 0) {
    print("Positive");
} else {
    print("Non-positive");
}
```
