# Standard Library: Collections

Operations for linked lists, hash tables, and float vectors.

## List Operations
- `push(list, value)`, `pop(list)`
- `push_front(list, value)`, `pop_front(list)`
- `insert(list, index, value)`
- `len(list)`: Gets length of list.

## Hash Table Operations
- `put(hash_table, key, value)`
- `get(hash_table, key)`
- `pairs(hash_table)`

## Vector Operations
- `linspace(start, end, count)`
- `dot(v1, v2)`, `cross(v1, v2)`
- `norm(vector)`
